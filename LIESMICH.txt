METZNER SOFTWARE ENTWICKLUNG – WEBSITE

LOKAL ANSEHEN
Die ZIP vollständig in einen Ordner entpacken. Anschließend index.html
öffnen. Die Dateien im Ordner assets müssen an ihrem Platz bleiben.

Optional: Falls Python bereits installiert ist, im entpackten Ordner ein
Terminal öffnen und diese lokale HTTP-Vorschau starten:
  python -m http.server 8000 --bind 127.0.0.1
Danach im Browser http://127.0.0.1:8000 öffnen. Mit Strg+C beenden.
